# Порядок: сервис уборок посуточной квартиры

Веб-приложение для шефа и уборщиц. Открывается в браузере телефона, его можно добавить на экран «Домой», и тогда оно работает как обычное приложение с push-уведомлениями.

## Что умеет

**Уборщица**
- Главная: новые уборки с кнопками «Принять» / «Не смогу», ближайшая уборка, список «Нужно докупить», инструкция по квартире.
- Календарь своих уборок.
- Уборка: «Начать», чек-лист по комнатам с галочками, загрузка видео-отчёта (с прогрессом), комментарий, «Завершить». Завершить нельзя, пока не отмечены все пункты; видео необязательно.
- «Докупить»: общий список. Отметка «Куплено» с суммой и фото чека, сумма автоматически идёт в компенсацию.
- «Сообщить о проблеме»: поломка, вещь, которую забыли гости, или другое, с фото.
- «Заработок»: сколько к выплате, сколько заработано за месяц, история выплат.
- Push-уведомления: новая уборка, изменение или отмена, напоминание вечером накануне, выплата.

**Шеф**
- Обзор: что нужно назначить (новые брони, отказы), проблемы, покупки, сумма к выплате, сегодняшние уборки с прогрессом, последние отчёты.
- Календарь всех уборок; цвет точки показывает уборщицу.
- Создание, изменение, отмена и переназначение уборок, сумма оплаты на каждую уборку.
- Просмотр отчётов: видео, чек-лист, комментарий.
- Проблемы: отметить «Решено» с комментарием, автор получает уведомление.
- Выплаты: баланс каждой уборщицы (уборки + покупки), кнопка «Выплатить», история.
- Команда: добавить уборщицу, сменить пароль, отключить доступ.
- Редактор чек-листов (обычная и генеральная уборка).
- Квартира и тарифы: адрес, инструкция, время выезда и заезда, ставки, срок хранения видео.
- Бронирования (iCal): ссылки с Авито, Суточно.ру, Airbnb, Booking. После каждого выезда гостя уборка создаётся сама. Если бронь отменили, уборка тоже отменяется.

## Установка на сервер и автообновление с GitHub

Сервер раз в минуту проверяет ветку `main` в GitHub. Если появился новый код, он сам скачивает его, ставит зависимости и перезапускает сервис. Выкладка = `git push`.

Как устроено на сервере:
- `/opt/poryadok` — код (git-клон репозитория);
- `/var/lib/poryadok` — база `poryadok.db` и `uploads/` с видео (при обновлениях не трогается; для бэкапа копируйте эту папку);
- `/etc/poryadok/accounts.json` — стартовые аккаунты (создаются при первом запуске; потом пароли меняются в приложении, файл можно удалить);
- `/etc/poryadok/env` — настройки сервера, например `DOMAIN=uborka.ru`;
- службы: `poryadok` (приложение), `poryadok-update.timer` (автообновление), `caddy` (HTTPS).

Первая установка на чистый Ubuntu 22.04/24.04 (от root): создать `/etc/poryadok/accounts.json` по образцу `config/accounts.example.json` и запустить `deploy/bootstrap.sh` (его можно вставить в терминал целиком). Скрипт дождётся появления кода в репозитории, установит Node.js 22 и Caddy, настроит службы и выведет адрес сайта.

Полезные команды:
```bash
journalctl -u poryadok -f                 # логи приложения
journalctl -u poryadok-update -n 30       # история автообновлений
systemctl restart poryadok                # перезапуск
echo 'DOMAIN=uborka.ru' > /etc/poryadok/env && bash /opt/poryadok/deploy/install.sh   # свой домен
```

## Как уборщице установить приложение на телефон

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран „Домой“» → открыть с иконки → на главной нажать «Включить уведомления».
- **Android:** открыть в Chrome → меню ⋮ → «Добавить на главный экран» → «Включить уведомления».

## Посмотреть локально

```bash
npm install
npm run demo   # примерные данные (только на пустой базе)
npm start      # http://localhost:3000
```

Для локальной проверки скопируйте `config/accounts.example.json` в `config/accounts.json` (входы `shef / shef2026`, `anna / anna2026`, `maria / maria2026`).

## Устройство

- `server/` — Node.js + Express, база SQLite (встроена в Node 22, внешних баз не нужно).
  - `api.js` — все запросы, `ical.js` — синхронизация броней, `jobs.js` — фоновые задачи (iCal каждые 30 минут, напоминания, удаление старых видео), `notify.js` — уведомления и web push.
- `public/` — интерфейс без сборки: ES-модули, `css/app.css`, экраны в `js/views/`.

## Видео

Видео 1–3 минуты с телефона весит 100–500 МБ. Загрузка идёт напрямую на сервер с прогрессом, лимит 4 ГБ на файл. Чтобы не переполнять диск, видео удаляются через 30 дней (меняется в настройках), а чек-листы и комментарии остаются.

Видео с iPhone в формате HEVC (.mov) воспроизводятся в Safari и на большинстве современных устройств. Если на компьютере видео не играет, включите на iPhone «Настройки → Камера → Форматы → Наиболее совместимый».
